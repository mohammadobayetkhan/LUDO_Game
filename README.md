# Modern Ludo Game

A desktop board-game package written in **C11** with the **raylib** library.
It contains **Ludo** and **Snakes & Ladders**, a computer opponent, sound effects,
and **Wi-Fi / hotspot multiplayer** (no internet needed).
Everything - board, snakes, ladders, dice and most sounds - is drawn or generated by code,
so the whole game is one source file (`src/main.c`, about 7,700 lines).

## Features

### Ludo
- **2 Players**, **4 Players**, **Team Mode** (Red + Blue vs Green + Yellow) and **VS Computer**
- Full rules: a 6 to leave the yard, 52-cell track, 8 safe cells, captures, private home lanes,
  exact roll to finish, extra turn on a 6
- Team mode: teammates never capture each other; a player whose tokens are all home rolls for the teammate

### Snakes & Ladders
- 10 x 10 board (1-100) with 8 ladders and 8 snakes drawn in code
- Roll a 1 to start, exact roll to reach 100, a roll of 1 gives another turn
- 2 Players or VS Computer

### Play on Wi-Fi / hotspot
- One player is the **HOST**; the others choose **JOIN A GAME** and type the host's IP address
- Everybody must be on the same Wi-Fi or the same phone/PC hotspot
- TCP port **7777** (allow the game in the firewall if asked)
- Ludo 2P, 4P, Team 2v2 and Snakes & Ladders 2P are supported online
- The host runs all game rules; clients send only "roll" and "pick token" requests

### Computer player
Scores every legal move (progress, leaving the yard, reaching home, safe cells,
captures, threats from enemy tokens) and plays the best one.

### Sound
Soft bell / wood / glide sounds generated by the program at start-up, plus three
embedded MP3 effects. If an MP3 cannot be decoded, the built-in sound is used instead.

## Controls

| Input | Action |
|---|---|
| Mouse | Click menu buttons, the dice, and glowing tokens |
| `Space` | Roll the dice |
| `Enter` / `4` (menu) | Start Ludo for 2 / 4 players |
| `M` | Mute / unmute |
| `R` | Restart the current game |
| `Esc` | Back / return to the main menu |

## Build

You need a C compiler (GCC) and [raylib](https://github.com/raysan5/raylib).

**Linux / macOS**
```bash
make          # builds ./ludo
make run
```

**Windows (w64devkit / MinGW)**
```bash
make                                     # uses RAYLIB_PATH=C:/raylib/raylib/src
make RAYLIB_PATH=D:/libs/raylib/src      # if raylib is somewhere else
```

Manual command (Windows):
```bash
gcc src/main.c -o ludo.exe -IC:/raylib/raylib/src -LC:/raylib/raylib/src \
    -lraylib -lopengl32 -lgdi32 -lwinmm -lws2_32
```

Manual command (Linux):
```bash
gcc src/main.c -o ludo $(pkg-config --cflags --libs raylib) -lm
```

## How the code is organised (`src/main.c`)

1. Constants, enums and data structures (`Token`, `Player`, `SnakeGame`, `Layout`, `Game`)
2. Network state and seat helpers
3. Sound synthesis and embedded MP3 loading
4. Ludo board geometry and rules (`GetLegalMoves`, `MoveToken`, `CheckCapture`, `CheckWinner`, `AdvanceTurn`)
5. Computer player (`BotChooseToken`)
6. Snakes & Ladders logic
7. Networking: sockets, message framing, snapshots, lobby
8. Menu, `UpdateGame()` and all drawing functions
9. `main()` - `InitWindow` -> loop { `UpdateGame`; `DrawGame` }

## Known limitations
- LAN / hotspot only, IPv4, no encryption or password
- If the host leaves, the online game ends (no reconnect)
- No computer player in 4-player, team or online modes
