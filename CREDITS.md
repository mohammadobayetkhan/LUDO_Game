## Sound effects
Three sound effects are stored inside `src/main.c` as Base64 text, so the game
stays a single executable. All other sounds are generated by the program itself.

| Used for | Source (as named in the code) |
|---|---|
| Dice roll | universfield - "video-game-bonus" (323603) |
| New game start | freesound - "game-start" (6104) |
| Token captured / eaten by a snake | dragon-studio - "game-over retro 8bit" (499656) |

Please check each file's licence on its original website before redistributing
and keep the author credit.
